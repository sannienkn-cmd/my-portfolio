# Personal Portfolio — Sannie Kyalo

A responsive personal portfolio home page built with semantic HTML5 and CSS3 as part of **CSN 1101: Web Technologies and Internet Applications** at KCA University.

## Features

- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<footer>`)
- Fully responsive layout — works from 320px phones up to desktop
- Clean, consistent colour palette and typography
- Mobile hamburger navigation
- External CSS only — no inline styles or `<style>` blocks
